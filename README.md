# 📰 每日早报

> 自动化个人日报系统，包含 RSS 聚合、天气、时间进度、微博热搜等内容

---

## 🚀 功能导航

| 功能 | 文件 | 说明 |
|:---:|:---:|:---|
| 📰 **每日早报** | [README.md](README.md) | 本文件，每天北京时间 06:00 自动更新 |
| 🚀 **Hacker News** | [HACKERNEWS.md](HACKERNEWS.md) | 每天 08:00 自动抓取 HN 精选 |
| 🎲 **有趣语录** | Issues | 每 45 分钟推送毒鸡汤/一言/土味情话等 |

---

## 🎲 有趣语录推送

每 **45 分钟**自动推送一条有趣内容到 Issue，包含：

| 类型 | 说明 |
|:---:|:---|
| 🍵 毒鸡汤 | 让你认清现实的毒辣鸡汤 |
| ✨ 一言 | 精彩的一句话 |
| 🌹 土味情话 | 甜到发腻的情话 |
| 🐕 舔狗日记 | 舔狗的日常记录 |
| 📖 文案 | 朋也风格文案 |
| 🎵 网易热评 | 网易云音乐热门评论 |
| 🌈 彩虹屁 | 夸人的彩虹屁 |
| 😴 早点睡 | 劝你早点睡的文案 |

**推送时间**：北京时间 06:00 - 23:00（每 45 分钟一次）
**静默时间**：北京时间 23:00 - 06:00

---

## ⚙️ 项目配置

配置文件: [config.json](config.json)

## 📝 使用说明

1. **Fork 本仓库** 或直接使用
2. **配置 Secrets**:
   - `LLM_API_KEY` - AI 服务 API 密钥
3. **启用 Actions** - GitHub Actions 会自动运行
4. **查看报告** - 每日自动生成在对应 Markdown 文件中
